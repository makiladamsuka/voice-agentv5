# Nema Kiosk Robot — 3D Component Models

Place your 3D printer files and CAD designs in this directory.

## Directory Structure

- `stl_parts/`  
  *Place your printable `.stl` or `.3mf` files here. These will render interactively directly in the web browser on GitHub.*

- `assemblies/`  
  *Place your full CAD assemblies here (e.g., `.step`, `.f3d`, `.sldprt` files).*

## Printing Guidelines (Recommended)

- **Filament:** PLA or PETG (PETG is recommended for load-bearing brackets and joints).
- **Infill:** 15% to 25% (Gyro / Grid infill for strength).
- **Supports:** Enable supports for overhang brackets.
